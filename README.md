# Selenium Java Automation Framework\n\n**Enterprise-Grade Test Automation Framework**\n\n**Author:** Vijay Chavan | Senior Automation QA Engineer | SDET  \n**LinkedIn:** https://www.linkedin.com/in/vijaychavhan08  \n**GitHub:** https://github.com/vijaychavn08-hue  \n\n---\n\n## 📋 Overview\n\nA professional, enterprise-scale Selenium WebDriver automation framework built with Java, Maven, TestNG, and Cucumber BDD. Demonstrates industry-standard test automation architecture with Page Objects, Components, reusable utilities, JSON locator management, and CI/CD integration.\n\n**Portfolio Disclaimer:** This is a demonstration framework using public demo applications (SauceDemo). It does not contain proprietary or confidential company code.\n\n---\n\n## 🛠 Technology Stack\n\n- **Java 11+** - Programming language\n- **Selenium WebDriver 4.15+** - Browser automation\n- **Maven 3.8+** - Build automation\n- **TestNG 7.8+** - Test framework\n- **Cucumber JVM 7.14+** - BDD framework\n- **Allure 2.21+** - Test reporting\n- **Jackson 2.16+** - JSON processing\n- **SLF4J/Logback 2.0+** - Logging\n- **Java Faker 1.0+** - Test data generation\n- **GitHub Actions** - CI/CD\n\n---\n\n## 🏗 Architecture\n\n```\nGherkin Feature Files\n    ↓\nCucumber Step Definitions\n    ↓\nPage Objects (Business-level methods)\n    ↓\nComponents (Technical implementation)\n    ↓\nCore Framework (DriverManager, WaitUtils)\n    ↓\nSelenium WebDriver\n```\n\n### Design Principles\n\n✅ **Page Object Model (POM)** - Encapsulate UI interactions  \n✅ **Component Architecture** - Separation of concerns  \n✅ **ThreadLocal Driver** - Thread-safe parallel execution  \n✅ **JSON Locator Repository** - Externalized selector management  \n✅ **BDD Approach** - Business-readable scenarios  \n✅ **Allure Reporting** - Detailed test reports  \n\n---\n\n## 🚀 Quick Start\n\n```bash\n# Clone repository\ngit clone https://github.com/vijaychavn08-hue/selenium-java-automation-framework.git\ncd selenium-java-automation-framework\n\n# Run all tests\nmvn clean test\n\n# Run smoke tests\nmvn clean test -Dgroups=smoke\n\n# Generate Allure report\nmvn allure:report\nallure serve allure-results\n```\n\n---\n\n## 📝 Test Scenarios\n\n✅ Login (valid, invalid, locked user)  \n✅ Product browsing and filtering  \n✅ Add/remove from cart  \n✅ Checkout process  \n\n---\n\n## 📚 Documentation\n\nSee full documentation in [docs/](docs/) folder.\n\n---\n\n## 📄 License\n\nMIT License - See LICENSE file\n"
